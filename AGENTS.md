# StoryFormatDetector Agent Pointer

This focused package keeps durable project rules in public contributor and
architecture documentation.

1. Read `README.md` for scope, supported formats, and the distinction between
   byte signatures and extension fallback.
2. Read `CONTRIBUTING.md` before changing detection behavior, dependencies,
   public API, or verification.
3. Use `docs/DOCMAP.yaml` to route documentation updates.
4. Read `docs/architecture/detection-policy.md` for detection-policy changes and
   `docs/process/testing.md` for test changes.
5. Read `docs/process/consumer-adoption.md` before changing consumer-visible
   behavior or preparing a release.

Load only the documentation relevant to the active task. Keep normative rules
in those public files rather than expanding this pointer.
